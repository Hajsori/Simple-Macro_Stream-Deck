With the Simple Macro Stream Deck Plugin you can control Simple Voice Chat with your Stream Deck!

This plugin requires the [Simple Macro](https://github.com/Hajsori/Simple-Macro) Minecraft mod! You can download it on [Modrinth](https://modrinth.com/mod/simple-macro) and on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/simple-macro).
